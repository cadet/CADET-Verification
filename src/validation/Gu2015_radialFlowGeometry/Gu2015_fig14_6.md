Reproduction of Fig. 14.6 from:

    T. Gu, "Mathematical Modeling and Scale-Up of Liquid Chromatography",
    2nd ed., Springer, 2015, Chapter 14 ("Multicomponent Radial Flow

Self-contained script: model definition, run, comparison plot and

===========================================================================
1. Case identification
===========================================================================
Fig. 14.6 (p. 210) is a 3-component affinity RFC simulation with
inward flow: frontal loading of a protein (component 1), a wash stage, and
an elution stage using a soluble ligand (component 2). Component 3 is the
protein-ligand complex (PL) formed by a *liquid-phase* reversible reaction
between components 1 and 2; it forms/leaves in the mobile and pore liquid
and never binds the stationary phase.

The model is given in the book: Chapter 10, Secs. 10.1-10.5 (the
"AFFINITY" model, originally posed for axial flow) combined with Chapter
14, Sec. 14.6 ("Extensions of the General Multicomponent Rate Model for
RFC"), which states that "the addition of reaction terms for the
interaction between a macromolecule and the soluble ligand involves the
bulk-fluid phase, but it does not touch the characteristic terms of an RFC
model" -- i.e. the Chapter 10 reaction terms carry over unchanged into the
Chapter 14 RFC transport operator (Eq. 14.7/14.8).

Parameters are taken from: p. 210 states "the parameters for simulation of Fig. 14.6
are the same as those for Fig. 11.14, except inward flow", but Chapter 11
covers ion-exchange chromatography and contains no Fig. 11.14 (only an
unrelated Eq. 11.14 on p. 162). The same paragraph continues: "Compared
with AFC for Fig. 10.14, Fig. 14.6 for RFC has almost no practical
difference when the two figures are superimposed because comparable
physical parameters ... are used in the two cases." Fig. 10.14 (p. 138, a
"Chromulator AFFINITY simulator" GUI screenshot) reproduces the same
frontal-loading shape, elution-front timing, and complex-peak
height/timing as the rendered Fig. 14.6, consistent with this stated
RFC/AFC near-equivalence. "Fig. 11.14" is therefore read as an erratum for
"Fig. 10.14", and this script takes all Chapter-10-model dimensionless
parameters directly from the Fig. 10.14 GUI screenshot (p. 138), applied to
the RFC geometry of Chapter 14 with V0=0.04 (p. 210).

===========================================================================
2. Governing model (Ch. 10, Secs. 10.1-10.5)
===========================================================================
Reactions (Eqs. 10.5-10.6):
    P + I <=(ka2,kd2)=> PI            (component 1 + component 2 -> 3)
    P + L <=(ka1,kd1)=> PL            (component 1 binds immobilized ligand)
Only component 1 (protein) has a bound state; components 2 (soluble ligand)
and 3 (complex) never bind the stationary phase (they are transported by
bulk convection/dispersion and pore diffusion only).

Bulk-fluid governing equation (Eq. 10.10, dimensionless, axial form; Sec.
14.6 replaces the axial d/dz, d2/dz2 terms with the RFC operator of
Eq. 14.7 while keeping the reaction term unchanged):
    -(1/PeLi) d2cbi/dz2 + dcbi/dz + dcbi/dtau + xi_i*(cbi - cpi|r=1)
        - f(i)*[Da2a*cb1*(C02/C0i)*cb2 - Da2d*(C03/C0i)*cb3] = 0
    f(1)=f(2)=+1 (protein & ligand consumed by reaction),
    f(3)=-1 (complex produced by reaction).

Particle-phase governing equation (Eq. 10.11, dimensionless):
    g(i)*(1-eps_p)*dc*pi/dtau + eps_ap*dcpi/dtau
        - f(i)*eps_ap*[Da2a*cp1*(C02/C0i)*cp2 - Da2d*(C03/C0i)*cp3]
        - eta_i*(1/r^2) d/dr(r^2 dcpi/dr) = 0
    g(1)=1, g(2)=g(3)=0 (only component 1 has a bound-phase term).

Bound-phase kinetics for component 1 only (Eq. 10.12/10.9):
    dc*p1/dtau = Da1a*cp1*(c1_inf - c*p1) - Da1d*c*p1
a single-component kinetic (non-equilibrium) Langmuir isotherm with finite
capacity c1_inf (the dimensionless immobilized-ligand site density,
c1_inf = C_inf,1/C0_1).

===========================================================================
3. CADET model and modeling choices
===========================================================================
- Bulk transport: COLUMN_MODEL_1D with GEOMETRY='RADIAL_FLOW_CYLINDER_SHELL',
  discretizing the bulk PDE directly in the physical radial coordinate X (no
  axial-column substitution). Per Eq. 14.15, Db_i(X) must scale with the
  local velocity v(X) so that Pe_i is constant in Gu's transformed V-space;
  this is represented via CADET's `COL_DISPERSION_DEP='POWER_LAW'` with
  `COL_DISPERSION_DEP_EXPONENT=1.0`, which multiplies COL_DISPERSION[i] by
  the operator's actual local radial velocity at each cell face, giving
  Db_i(X) ~ v(X) exactly. The analogous position dependence of the film
  mass-transfer coefficient Bi_i(V) (Eq. 14.16) is represented the same way
  via `FILM_DIFFUSION_DEP='POWER_LAW'` with `EXPONENT=1/3`, evaluated at the
  true local velocity everywhere -- reproducing the paper's own "iave=0"
  (fully position-dependent) treatment rather than its "iave=2"
  constant-Bi-at-V=0.5 approximation (also available here as a fallback,
  see `film_diffusion_velocity_dep` in `get_model()`).
- Particle transport: GENERAL_RATE_PARTICLE (film + pore diffusion,
  spherical particles), identical transport parameters for all 3 components
  since the paper's own PeL/eta/Bi/ExF table (Fig. 10.14 GUI) happens to be
  numerically identical across all three components (PeL=300, eta=10,
  Bi=40, ExF=0.8). The size-exclusion factor ExF maps directly onto
  CADET's `PORE_ACCESSIBILITY` factor, see Sec. 4.
- Binding: MULTI_COMPONENT_LANGMUIR, IS_KINETIC=1, active for component 1
  only (nbound=[1,0,0]); components 2 and 3 access the particle pore liquid
  (film/pore diffusion enabled for all 3) but never bind. CADET's
  `LangmuirBinding::fluxImpl()` residual is `kD[i]*y - kA[i]*yCp*qMax[i]*
  qSum`, i.e. dq/dt = ka*cp*(qmax-q) - kd*q with qSum skipping components
  that have zero bound states, so components 2 and 3 (nbound=0) correctly
  do not participate in the isotherm.
- Reaction: MASS_ACTION_LAW, one reaction P + I -> PI, applied identically
  on (a) the column unit's bulk liquid phase and (b) the particle type's
  pore liquid phase, with the same rate constants ka2, kd2 in both places.
  This mirrors Eq. 10.11 exactly: both the pore-diffusion accumulation term
  (eps_ap*dcpi/dtau) and the pore-liquid reaction term carry the same
  eps_ap prefactor, so when the equation is divided through to isolate
  dcpi/dtau (the form CADET's particle-phase residual solves), eps_ap
  cancels identically and the same physical rate constants govern the
  reaction in bulk and pore liquid alike.

Daa/Dad row convention: the Fig. 10.14 GUI table lists a "Daa/Dad" column
per component row, but the model has only two independent Damkohler pairs:
Da1a/Da1d (component 1's own binding to the immobilized ligand, Eq. 10.12)
and Da2a/Da2d (the shared bulk+pore reaction rate constants for P+I<->PI,
Eqs. 10.10/10.11, identical in every component's governing equation). Row 1
(protein, the only row with nonzero C_inf) is read as Da1a/Da1d; row 2
(soluble ligand, the reaction's second reactant) as Da2a/Da2d; row 3
(complex) is (0,0) since it has no independent kinetic process beyond the
shared reaction already captured via row 2. Both rows report the same
values (Daa=2, Dad=0.2), so this reading choice does not affect the
simulation (Da1a=Da2a=2, Da1d=Da2d=0.2 either way).

===========================================================================
4. Size-exclusion factor ExF and CADET's pore accessibility factor
===========================================================================
Per Sec. 10.3 / Eq. 8.8 (p. 125), size exclusion is modeled in the book by
replacing the particle porosity eps_p with an "accessible" particle
porosity eps_ap = ExF*eps_p in the pore-liquid accumulation and
diffusion/reaction terms only, while the solid-phase accumulation term (the
(1-eps_p) prefactor multiplying dq*/dt in Eq. 10.11) keeps using the true
total porosity eps_p.

CADET implements precisely this formulation via the component-dependent pore accessibility factor
`PORE_ACCESSIBILITY` (F_acc,i). The particle pore-liquid balance reads

    dcp_i/dt + [(1-eps_p)/(F_acc,i*eps_p)]*dcs_i/dt
        = Dp_i*Lap_r(cp_i) + f^p_react,i
          + [(1-eps_p)/(F_acc,i*eps_p)]*f^s_react,i

with the film boundary condition

    kf_i*(cl_i - cp_i|r=Rp) = F_acc,i*eps_p*Dp_i*dcp_i/dr|r=Rp

(`ParticleDiffusionOperatorBase.cpp:213`,
`ParticleDiffusionOperatorFV.cpp:407,528`). The numerator of the
solid-phase weight is the *true* (1-eps_p), not (1-F_acc*eps_p): the
product F_acc,i*eps_p = eps_ap replaces the porosity in the pore-liquid,
transport and reaction roles only. Dividing the book's Eq. 10.11 through by
eps_ap gives

    dcp_i/dtau + g(i)*[(1-eps_p)/eps_ap]*dc*p_i/dtau
        = (eta_i/eps_ap)*Lap_r(cp_i) + f(i)*[reaction]

which is the same equation term by term under F_acc,i*eps_p = eps_ap.

This case study therefore uses the paper's own values directly and unmodified: `PAR_POROSITY` = eps_p = 0.45, `PORE_ACCESSIBILITY` = ExF = 0.8
(identical for all three components), `MCL_QMAX[0]` = C_inf,1 = 1e-5. No derived or corrected parameter enters anywhere. The reported PeL/eta/Bi
groups are unaffected, since eps_ap enters them (Sec. 5) only through the product F_acc*eps_p that CADET forms itself. Achieved chromatogram NRMSE:
0.97%/3.49%/3.41% (protein/ligand/complex), independently confirmed by
cross-validating the FV and DG bulk discretizations against each other.

Note on CADET's documented caveat that `PORE_ACCESSIBILITY` "should not be
used in combination with any binding model": that warning concerns the
physical interpretation of the saturation capacity when *different* solutes
have *different* accessible porosities while competing for one shared
population of ligands -- a single per-component qmax then cannot be made
consistent with the shared (1-eps_p) solid phase. Neither condition arises
here: ExF is identical for all three components, and only component 1 has a
bound state (nbound=[1,0,0]), so nothing component-dependent ever enters
the isotherm.

For reference, the alternative of collapsing both porosities into CADET's
`PAR_POROSITY` alone (PAR_POROSITY = eps_ap = 0.36, F_acc = 1) would give
the solid-fraction weight (1-eps_ap) = 0.64 instead of the book's
(1-eps_p) = 0.55 -- a factor (1-eps_ap)/(1-eps_p) = 1.164 (16.4%)
overstatement of the protein binding capacity per unit particle volume,
raising the NRMSE to 8.92%/3.15%/5.47%. Since the kinetic Langmuir ODE
dq/dt = ka1*cp1*(qmax1-q1) - kd1*q1 is exactly linear in qmax1 at fixed
ka1/kd1, that mismatch can be removed in closed form by rescaling
qmax1 -> qmax1*(1-eps_p)/(1-eps_ap); this was verified to reproduce the
`PORE_ACCESSIBILITY` setup above to solver tolerance (max. relative outlet
deviation 1.1e-9 at ABSTOL=1e-16/RELTOL=1e-12). The F_acc route is used
here because it requires no derived parameter at all.

===========================================================================
5. Reparameterization (paper's dimensionless groups -> CADET's
   dimensional/physical parameters)
===========================================================================
Definitions (Ch. 3/10 for Pe/Bi/eta/Da; Ch. 14 Eq. 14.1/14.7/14.16 for the
RFC-specific V0/time-normalization/Bi(V) treatment), applied to the native
radial geometry (physical radial coordinate X):
    Pe_Li  = v(X1)*(X1-X0)/Db_i,V=1        Bi_i = k_i*Rp/(eps_ap*Dp_i)
    eta_i  = eps_ap*Dp_i*(X1-X0)/(Rp^2*v_char)   (Rp SQUARED -- dimensionally
        required for eta to be dimensionless)
    tau    = v_char*t/(X1-X0),  v_char := 2*v(X1)*X1/(X1+X0)  (transit-time-
        harmonic-mean velocity, required so a non-retained tracer's mean
        transit time equals tau=1 exactly)
    V0 = X0^2/(X1^2-X0^2)
    Da1a = L*ka1*C0_1/v_char,  Da1d = L*kd1/v_char   (component 1's binding,
        L := X1-X0)
    Da2a = L*ka2*C0_1/v_char,  Da2d = L*kd2/v_char   (shared P+I reaction;
        per the book's own stated convention on p. 135: "For convenience,
        Da2a's definition uses C0_1 instead of C0_2 ... Note that Gu et al.
        [17] used C0_2 instead of C0_1" -- this script follows the book
        chapter's own convention, i.e. C0_1.)
    c1_inf = C_inf,1/C0_1  (dimensionless immobilized-ligand site density)
    Bi_i,V = [(1-V0)/(V+V0)]^(1/6) * Bi_i,V=1   (Eq. 14.16; used only for
        the V=0.5 "iave=2" fallback average below, an O(V0)=O(4%) effect)

A dimensionless model admits a free choice of absolute physical scale, so
we fix convenient scales -- X1=0.05 m (outer, inward-flow inlet), Rp=5e-5 m,
v(X1)=1e-4 m/s, reference concentration unit = 1 [arbitrary consistent
unit] -- and invert the above definitions:
    X0 = X1*sqrt(V0/(1+V0));  L := X1-X0
    v_char = 2*v(X1)*X1/(X1+X0)
    Db_i|V=1 = v(X1)*L/PeL_i    (COL_DISPERSION[i] := Db_i|V=1/v(X1), so that
        COL_DISPERSION_DEP='POWER_LAW' with EXPONENT=1 gives
        Db_i(X) = COL_DISPERSION[i]*v(X) = Db_i|V=1*v(X)/v(X1))
    Dp_i    = eta_i*Rp^2*v_char/(eps_ap*L)
    k_i|V=1 = Bi_i|V=1 * eta_i * Rp * v_char/L
    IAVE2 (constant-Bi approximation at V=0.5, per the paper's own
        documented "iave=2" mode): k_i|avg = k_i|V=1 * [(1-V0)/(0.5+V0)]^(1/6)
    ka1 = Da1a*v_char/(L*C0_1);  kd1 = Da1d*v_char/L
    ka2 = Da2a*v_char/(L*C0_1);  kd2 = Da2d*v_char/L
    qmax1 = C_inf,1  (used unmodified; see Sec. 4)
    tau -> t_phys = tau*L/v_char
    Q (inlet volumetric flow) = v(X1)*X1*2*pi*H*eps_b   (CADET's
        _curVelCoeff = Q/(2*pi*H*eps_b), currentVelocity(X)=_curVelCoeff/X,
        so v(X1) == Q/(2*pi*H*eps_b*X1) by construction)
The dividing-out of the reference velocity in COL_DISPERSION/FILM_DIFFUSION
above is required because CADET's POWER_LAW parameter dependency evaluates
at the true local velocity everywhere, not at a fixed reference velocity --
supplying the reference-velocity coefficient itself would double-count the
velocity scaling.

Component-3 (complex) note: since C0_3 is not known a priori, the book
nondimensionalizes component 3 using C0_1 (Cb3 = cb3*C0_1), consistent with
the table itself listing C0(row 3) = C0(row 1) = 0.000001 identically.
