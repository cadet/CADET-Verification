# Gu (2015), Fig. 14.6 — affinity RFC with inward flow

Reference:

    T. Gu, "Mathematical Modeling and Scale-Up of Liquid Chromatography",
    2nd ed., Springer, 2015, Chapter 14 ("Multicomponent Radial Flow
    Chromatography"), p. 210: "Simulation of affinity RFC with inward flow".

`Gu2015_fig14_6.py` holds the model definition, the simulation run, the
comparison plot and the validation metrics.

## The case

A three-component affinity separation in an inward-flow RFC, run in three
stages: frontal loading of a protein (component 1), a wash, and elution with a
soluble ligand (component 2). Component 3 is the protein–ligand complex, formed
by a reversible reaction in the liquid phase; it exists in the bulk and pore
liquid and never binds the stationary phase.

The model is Gu's Chapter 10 affinity model, originally written for axial flow,
combined with Ch. 14, Sec. 14.6, which notes that the reaction terms concern
the bulk-fluid phase only and leave the characteristic RFC terms untouched. The
Chapter 10 reaction terms therefore carry over unchanged into the RFC transport
operator of Eqs. 14.7/14.8.

### Where the parameters come from

Page 210 states that the parameters of Fig. 14.6 are those of "Fig. 11.14,
except inward flow". Chapter 11 covers ion-exchange chromatography and has no
Fig. 11.14 — only an unrelated Eq. 11.14 on p. 162. The same paragraph goes on
to say that Fig. 14.6 and the axial-flow Fig. 10.14 are practically
indistinguishable when superimposed, because comparable physical parameters are
used in both. Fig. 10.14 (p. 138) is a GUI screenshot of the affinity simulator
and does show the same loading shape, elution timing and complex peak as
Fig. 14.6. "Fig. 11.14" is therefore read as a typo for "Fig. 10.14", and all
dimensionless parameters are taken from that screenshot, combined with the RFC
geometry of Ch. 14 with V0 = 0.04 from p. 210.

## Governing model (Ch. 10, Secs. 10.1–10.5)

Two reactions (Eqs. 10.5–10.6):

    P + I <=(ka2,kd2)=> PI      component 1 + component 2 -> component 3
    P + L <=(ka1,kd1)=> PL      component 1 binds the immobilized ligand

Only the protein has a bound state. The soluble ligand and the complex enter
the particle pore liquid through film and pore diffusion but never adsorb.

Bulk phase (Eq. 10.10, dimensionless, here with the axial derivatives replaced
by the RFC operator of Eq. 14.7):

    -(1/PeLi) d2cbi/dz2 + dcbi/dz + dcbi/dtau + xi_i*(cbi - cpi|r=1)
        - f(i)*[Da2a*cb1*(C02/C0i)*cb2 - Da2d*(C03/C0i)*cb3] = 0

with f(1) = f(2) = +1 for the consumed reactants and f(3) = -1 for the product.

Particle phase (Eq. 10.11):

    g(i)*(1-eps_p)*dc*pi/dtau + eps_ap*dcpi/dtau
        - f(i)*eps_ap*[Da2a*cp1*(C02/C0i)*cp2 - Da2d*(C03/C0i)*cp3]
        - eta_i*(1/r^2) d/dr(r^2 dcpi/dr) = 0

with g(1) = 1 and g(2) = g(3) = 0, since only the protein has a bound phase.
Its binding is a kinetic Langmuir isotherm with a finite site density
(Eqs. 10.9/10.12):

    dc*p1/dtau = Da1a*cp1*(c1_inf - c*p1) - Da1d*c*p1

## Model choice

- Bulk transport uses `COLUMN_MODEL_1D` with
  `GEOMETRY='RADIAL_FLOW_CYLINDER_SHELL'`, so the bulk equation is discretized
  in the physical radial coordinate.
- Eq. 14.15 requires Db_i(X) to scale with the local velocity so that Pe_i
  stays constant in Gu's transformed V-space. That is
  `COL_DISPERSION_DEP='POWER_LAW'` with `EXPONENT=1`, which multiplies
  COL_DISPERSION[i] by the local radial velocity. The film mass-transfer
  coefficient (Eq. 14.16) is handled the same way with
  `FILM_DIFFUSION_DEP='POWER_LAW'` and `EXPONENT=1/3`. Both reproduce Gu's
  fully position-dependent "iave=0" mode; his "iave=2" approximation, which
  evaluates k_i once at V = 0.5, is available via
  `film_diffusion_velocity_dep=False`.
- Particles are `GENERAL_RATE_PARTICLE` with film and pore diffusion. All three
  components share the same transport parameters, because the Fig. 10.14 table
  happens to list identical values for all of them (PeL = 300, eta = 10,
  Bi = 40, ExF = 0.8).
- Binding is `MULTI_COMPONENT_LANGMUIR` with `IS_KINETIC=1` and
  `nbound=[1,0,0]`, so only the protein takes part in the isotherm.
- The reaction is a `MASS_ACTION_LAW` for P + I <-> PI, applied with the same
  rate constants both to the column's bulk liquid and to the particle's pore
  liquid. In Eq. 10.11 the pore accumulation term and the pore reaction term
  carry the same eps_ap prefactor, so dividing through to isolate dcpi/dtau —
  the form CADET solves — cancels eps_ap and leaves the same rate constants in
  both phases.

### Reading the Daa/Dad table rows

The Fig. 10.14 table lists a Daa/Dad pair per component row, but the model has
only two independent Damköhler pairs: Da1a/Da1d for the protein's binding to
the immobilized ligand (Eq. 10.12), and Da2a/Da2d for the shared P + I <-> PI
reaction (Eqs. 10.10/10.11). Row 1, the protein, is the only row with a nonzero
C_inf and is read as Da1a/Da1d; row 2, the soluble ligand, as Da2a/Da2d; row 3,
the complex, is (0, 0), since it has no kinetic process of its own. Both rows
carry the same numbers (Daa = 2, Dad = 0.2), so the reading does not change the
simulation either way.

## Size exclusion

Gu models size exclusion (Sec. 10.3, Eq. 8.8) by replacing the particle
porosity with an accessible porosity eps_ap = ExF*eps_p in the pore-liquid
accumulation, diffusion and reaction terms, while the solid-phase accumulation
term keeps the true porosity through its (1-eps_p) prefactor.

CADET expresses the same split through the component-dependent pore
accessibility factor: `PAR_POROSITY` is the true eps_p = 0.45 and
`PORE_ACCESSIBILITY` is ExF = 0.8, so the product enters pore transport and the
film boundary condition while the solid phase retains (1-eps_p). No correction
to the saturation capacity is needed; qmax_1 is the paper's own C_inf,1.

## From Gu's dimensionless groups to CADET parameters

Gu's definitions (Ch. 3 and 10 for Pe, Bi, eta and Da; Ch. 14 for the
RFC-specific quantities):

    Pe_Li  = v(X1)*(X1-X0)/Db_i,V=1        Bi_i = k_i*Rp/(eps_ap*Dp_i)
    eta_i  = eps_ap*Dp_i*(X1-X0)/(Rp^2*v_char)
    tau    = v_char*t/(X1-X0),   v_char := 2*v(X1)*X1/(X1+X0)
    V0     = X0^2/(X1^2-X0^2)
    Da1a   = L*ka1*C0_1/v_char,  Da1d = L*kd1/v_char     (L := X1-X0)
    Da2a   = L*ka2*C0_1/v_char,  Da2d = L*kd2/v_char
    c1_inf = C_inf,1/C0_1

v_char is the harmonic-mean transit velocity, chosen by Gu so that an
unretained tracer leaves the column at tau = 1. Both Damköhler pairs are scaled
with C0_1; the book states this convention explicitly on p. 135 and notes that
Gu et al. had used C0_2 for Da2a instead.

A dimensionless model fixes no absolute scale, so the physical one can be
chosen freely: X1 = 0.05 m (outer radius, which is the inlet for inward flow),
Rp = 5e-5 m, v(X1) = 1e-4 m/s and a unit reference concentration. Inverting the
definitions above then gives

    X0 = X1*sqrt(V0/(1+V0));  L := X1-X0
    v_char   = 2*v(X1)*X1/(X1+X0)
    Db_i|V=1 = v(X1)*L/PeL_i
    Dp_i     = eta_i*Rp^2*v_char/(eps_ap*L)
    k_i|V=1  = Bi_i|V=1 * eta_i * Rp * v_char/L
    ka1 = Da1a*v_char/(L*C0_1);   kd1 = Da1d*v_char/L
    ka2 = Da2a*v_char/(L*C0_1);   kd2 = Da2d*v_char/L
    qmax1 = C_inf,1
    Q     = v(X1)*X1*2*pi*H*eps_b

The flow rate Q is picked so that CADET's velocity at the outer radius,
Q/(2*pi*H*eps_b*X1), comes out as v(X1).

One conversion is easy to get wrong. Both power-law dependencies are evaluated
at the local velocity everywhere in the column, not at a fixed reference
velocity, so the configured coefficients have to be divided by the reference
velocity (or its cube root) first: COL_DISPERSION[i] = Db_i|V=1/v(X1) and
FILM_DIFFUSION[i] = k_i|V=1/v(X1)^(1/3). Supplying the reference-velocity
coefficients directly would count the velocity scaling twice.

Finally, C0_3 is not known in advance, so the book normalises the complex by
C0_1. The table reflects that by listing the same C0 for rows 1 and 3.
