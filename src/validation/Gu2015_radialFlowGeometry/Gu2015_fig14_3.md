# Gu (2015), Fig. 14.3 — binary frontal adsorption in an inward-flow RFC

Reference:

    T. Gu, "Mathematical Modeling and Scale-Up of Liquid Chromatography",
    2nd ed., Springer, 2015, Chapter 14 ("Multicomponent Radial Flow
    Chromatography"), p. 199: "Simulation of binary frontal adsorption in
    inward flow RFC".

`Gu2015_fig14_3.py` holds the model definition, the simulation run, the
comparison plot and the validation metrics.

## The case

Gu's Secs. 14.1–14.2 describe binary frontal adsorption (breakthrough) in an
inward-flow radial flow column (RFC): a multi-component Langmuir isotherm at
rapid equilibrium, film and pore diffusion into spherical particles, and both
the bulk dispersion coefficient and the film mass-transfer coefficient varying
with the interstitial velocity, which in a radial column varies with position.

All parameters are printed in the RATERFC.FOR data-file dump on the same page
as the figure:

    in/outward = -1 (inward flow)        V0 = 0.04000     iave = 0
    nsp=2  nelemb=15  nc=2  index=1 (frontal/breakthrough)
    epsip (eps_p) = 0.400   epsib (eps_b) = 0.400

    component   PeL     eta     Bi(V=1)   C0      a       b
        1       100.00  10.000  10.000    0.20000 1.000   2.000
        2        80.00   8.000   8.000    0.20000 10.000  20.000

Both components share a_i/b_i = 0.5, so their Langmuir saturation capacities
agree, as thermodynamic consistency requires.

## Model choice

Gu's Eqs. 14.1–14.2 and the accompanying particle equations are a general rate
model: film and pore mass transfer are resolved separately instead of being
lumped into one coefficient. The case is therefore set up with CADET's
`COLUMN_MODEL_1D`, `GEOMETRY='RADIAL_FLOW_CYLINDER_SHELL'` and
`GENERAL_RATE_PARTICLE`. The bulk equation is then discretized in the physical
radial coordinate, without any substitution to an equivalent axial column.

Both transport coefficients depend on the velocity (Gu, Sec. 14.3):

    Db_i(V) ~ V         (Eq. 14.15)  ->  COL_DISPERSION_DEP='POWER_LAW', EXPONENT=1
    k_i(V)  ~ V^(1/3)   (Eq. 14.16)  ->  FILM_DIFFUSION_DEP='POWER_LAW', EXPONENT=1/3

CADET evaluates both at the local velocity V(X) at every bulk discretization
point.

Setting `film_diffusion_velocity_dep=False` switches to Gu's own "iave=2"
approximation, which evaluates Eq. 14.16 once at V=0.5 instead of resolving
Bi_i(V) in space. It is kept as a comparison option; the default is the
position-dependent form.

## From Gu's dimensionless groups to CADET parameters

Gu's definitions (Ch. 3 and 14, in his notation):

    Pe_Li = v(X1)*(X1-X0)/Db_i,V=1        Bi_i = k_i*Rp/(eps_p*Dp_i)
    eta_i = eps_p*Dp_i*(X1-X0)/(Rp^2*v_char)
    tau   = v_char*t/(X1-X0),   v_char := 2*v(X1)*X1/(X1+X0)
    V0    = X0^2/(X1^2-X0^2)

His dimensionless Langmuir isotherm (Eq. 3.21),
cp*_i = a_i*cp_i/(1+sum_j b_j*C0_j*cp_j), is CADET's
`MULTI_COMPONENT_LANGMUIR` with ka_i = b_i, kd_i = 1 and qmax_i = a_i/b_i.

A dimensionless model fixes no absolute scale, so the physical one can be
chosen freely: X1 = 0.05 m (outer radius, which is the inlet for inward flow),
Rp = 5e-5 m, v(X1) = 1e-4 m/s, eps_b = eps_p = 0.4 (given by the paper) and a
unit reference concentration. Inverting the definitions above then gives

    X0 = X1*sqrt(V0/(1+V0));  L := X1-X0
    v_char = 2*v(X1)*X1/(X1+X0)
    Db_i|V=1 = v(X1)*L/PeL_i
    Dp_i     = eta_i*Rp^2*v_char/(eps_p*L)
    k_i|V=1  = Bi_i|V=1 * eta_i * Rp * v_char/L
    ka_i = b_i,  kd_i = 1,  qmax_i = a_i/b_i
    Q        = v(X1)*X1*2*pi*H*eps_b

The flow rate Q is picked so that CADET's velocity at the outer radius,
Q/(2*pi*H*eps_b*X1), comes out as v(X1).

One conversion is easy to get wrong. With `POWER_LAW`, CADET evaluates
Db_i(X) = COL_DISPERSION[i]*V(X) at the local velocity rather than at V=1, so
the configured values have to be divided by the reference velocity first:
COL_DISPERSION[i] = Db_i|V=1/v(X1) and
FILM_DIFFUSION[i] = k_i|V=1/v(X1)^(1/3) (`col_dispersion_value` and
`film_diffusion_value` in the script).
