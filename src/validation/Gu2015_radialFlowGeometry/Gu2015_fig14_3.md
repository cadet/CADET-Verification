===========================================================================
1. Case identification
===========================================================================
Governing model: Secs. 14.1-14.2 of Gu (2015). Binary frontal adsorption
(breakthrough) in an inward-flow radial flow column (RFC): multi-component
Langmuir isotherm at rapid equilibrium, film and pore diffusion into
spherical particles, with both the bulk dispersion coefficient and the film
mass-transfer coefficient varying with the local (radially varying)
interstitial velocity.

Target: Fig. 14.3 (PDF p. 207 / printed p. 199), reproduced from the exact
Fortran RATERFC.FOR data-file dump printed on the same page:

    in/outward = -1 (inward flow)        V0 = 0.04000     iave = 0
    nsp=2  nelemb=15  nc=2  index=1 (frontal/breakthrough)
    epsip (eps_p) = 0.400   epsib (eps_b) = 0.400

    component   PeL     eta     Bi(V=1)   C0      a       b
        1       100.00  10.000  10.000    0.20000 1.000   2.000
        2        80.00   8.000   8.000    0.20000 10.000  20.000

    (a_i/b_i = 0.5 for both components -> thermodynamically consistent
    Langmuir saturation capacity, as required.)

===========================================================================
2. Modeling choices
===========================================================================
Gu's Eqs. 14.1-14.2 (bulk transport) and the associated particle-phase
equations already constitute a genuine general rate model -- film and pore
mass transfer are resolved individually rather than lumped into a single
dispersion coefficient -- so CADET's `COLUMN_MODEL_1D` with
`GEOMETRY='RADIAL_FLOW_CYLINDER_SHELL'` and `GENERAL_RATE_PARTICLE`
particles are used directly: the bulk PDE is discretized in the true
physical radial coordinate (no axial-column substitution), and film/pore
diffusion into spherical particles is resolved explicitly, matching the
paper's model term-for-term.
Both transport coefficients are velocity-dependent (Sec. 14.3):
    Db_i(V) ~ V         (Eq. 14.15)  -> COL_DISPERSION_DEP='POWER_LAW', EXPONENT=1
    k_i(V)  ~ V^(1/3)   (Eq. 14.16)  -> FILM_DIFFUSION_DEP='POWER_LAW', EXPONENT=1/3
both evaluated by CADET at the true local radial velocity V(X) at every
bulk discretization point, rather than at a single reference velocity.

===========================================================================
3. Reparameterization: dimensionless (Gu 2015) -> dimensional (CADET)
===========================================================================
Definitions (Ch. 3/14, Gu's own notation):
    Pe_Li = v(X1)*(X1-X0)/Db_i,V=1        Bi_i = k_i*Rp/(eps_p*Dp_i)
    eta_i = eps_p*Dp_i*(X1-X0)/(Rp^2*v_char)
    tau   = v_char*t/(X1-X0),   v_char := 2*v(X1)*X1/(X1+X0)
    V0    = X0^2/(X1^2-X0^2)
Langmuir (Eq. 3.21, dimensionless): cp*_i = a_i*cp_i/(1+sum_j b_j*C0_j*cp_j)
    => CADET MULTI_COMPONENT_LANGMUIR (kd_i=1 convention): ka_i=b_i, qmax_i=a_i/b_i.

A dimensionless model is invariant to the choice of absolute physical scale,
so we fix X1=0.05 m (outer, inward-flow inlet radius), Rp=5e-5 m,
v(X1)=1e-4 m/s, eps_b=eps_p=0.4 (given), and a unit reference concentration,
then invert the definitions above:
    X0 = X1*sqrt(V0/(1+V0));  L := X1-X0
    v_char = 2*v(X1)*X1/(X1+X0)
    Db_i|V=1 = v(X1)*L/PeL_i
    Dp_i     = eta_i*Rp^2*v_char/(eps_p*L)
    k_i|V=1  = Bi_i|V=1 * eta_i * Rp * v_char/L
    ka_i = b_i,  kd_i = 1,  qmax_i = a_i/b_i
    Q (inlet volumetric flow) = v(X1)*X1*2*pi*H*eps_b, chosen so that
        CADET's currentVelocity(X1) = Q/(2*pi*H*eps_b*X1) equals v(X1) by
        construction.

CADET's `POWER_LAW` dependency evaluates Db_i(X) = COL_DISPERSION[i]*V(X)
(and analogously for film diffusion) at the true LOCAL velocity, not at
V=1; reproducing the paper's Db_i|V=1/k_i|V=1 therefore requires supplying
COL_DISPERSION[i] = Db_i|V=1/v(X1) and FILM_DIFFUSION[i] = k_i|V=1/v(X1)^(1/3),
so that CADET's own evaluation at V=v(X1) reproduces the paper's reference-
velocity coefficient exactly (`col_dispersion_value`/`film_diffusion_value`
below).

Case-specific note: `film_diffusion_velocity_dep=False` falls back to Gu's
own "iave=2" approximation (Eq. 14.16 evaluated once at V=0.5, i.e.
`k_avg` below) instead of the true position-dependent Bi_i(V); this is
provided as a documented ablation, not the default reproduction path.
