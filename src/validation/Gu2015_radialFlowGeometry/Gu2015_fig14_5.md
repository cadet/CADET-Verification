===========================================================================
Governing model
===========================================================================
Secs. 14.1-14.2: RFC general rate model, run in "elution with inert mobile
phase" mode (index=2): a finite rectangular pulse of duration tau_imp is
injected at tau=0, then the feed switches to pure (zero-concentration)
carrier for the remainder of the run (Eq. 14.12):

    Cf_i(tau)/C0_i = 1   for 0 < tau < tau_imp
                   = 0   otherwise

Both components follow a two-component Langmuir isotherm in rapid
equilibrium (Eq. 3.21), with film mass transfer and pore diffusion into
spherical particles, and velocity-dependent bulk dispersion (Eq. 14.15)
and film mass transfer (Eq. 14.16).

===========================================================================
Modeling choices
===========================================================================
- CADET's GENERAL_RATE_PARTICLE particle model (film + pore diffusion,
  spherical particles) is used directly, since the paper's own model is
  already a general rate model -- no lumping approximation is admissible.
- CADET's native COLUMN_MODEL_1D with GEOMETRY='RADIAL_FLOW_CYLINDER_SHELL'
  discretizes the bulk PDE directly in the physical radial coordinate X,
  representing the paper's RFC transport operator (Eq. 14.7/14.8) without
  an axial-column approximation or coordinate substitution.
- Velocity-dependent bulk dispersion (Eq. 14.15, Db_i(X) ~ v(X)) is
  represented via COL_DISPERSION_DEP='POWER_LAW' with EXPONENT=1.
- Velocity-dependent film mass transfer (Eq. 14.16, k_i(X) ~ v(X)^(1/3))
  is represented via FILM_DIFFUSION_DEP='POWER_LAW' with EXPONENT=1/3.
- MULTI_COMPONENT_LANGMUIR with IS_KINETIC=0 (rapid/local equilibrium)
  matches Eq. 3.21's dimensionless isotherm cp*_i = a_i*cp_i/(1+sum_j
  b_j*C0_j*cp_j); in dimensional form (C0_j cancels), this is CADET's
  MULTI_COMPONENT_LANGMUIR with ka_i=b_i, kd_i=1, qmax_i=a_i/b_i.

===========================================================================
Reparameterization: paper's dimensionless groups -> CADET's dimensional
parameters
===========================================================================
Definitions (Ch. 3/Ch. 14 notation):
    Pe_Li = v(X1)*(X1-X0)/Db_i,V=1        Bi_i = k_i*Rp/(eps_p*Dp_i)
    eta_i = eps_p*Dp_i*(X1-X0)/(Rp^2*v_char)   (Rp SQUARED -- dimensionally
        required for eta to be dimensionless)
    tau   = v_char*t/(X1-X0),  v_char := 2*v(X1)*X1/(X1+X0)  (transit-time-
        harmonic-mean velocity, required so a non-retained tracer's mean
        transit time equals tau=1 exactly)
    V0 = X0^2/(X1^2-X0^2)

A dimensionless model admits a free choice of absolute physical scale, so
we fix convenient SI scales -- X1=0.05 m (outer, inward-flow inlet),
Rp=5e-5 m, v(X1)=1e-4 m/s, eps_b=eps_p=0.4 (given), reference concentration
unit=1 mol/m^3 -- and invert the definitions above for CADET's dimensional
inputs:
    X0 = X1*sqrt(V0/(1+V0));  L := X1-X0
    v_char = 2*v(X1)*X1/(X1+X0)
    Db_i|V=1 = v(X1)*L/PeL_i
    Dp_i = eta_i*Rp^2*v_char/(eps_p*L)
    k_i|V=1 = Bi_i|V=1 * eta_i * Rp * v_char/L
    ka_i = b_i,  kd_i = 1,  qmax_i = a_i/b_i
    Q (inlet volumetric flow) = v(X1)*X1*2*pi*H*eps_b   (CADET's
        _curVelCoeff = Q/(2*pi*H*eps_b), currentVelocity(X)=_curVelCoeff/X,
        so v(X1) == Q/(2*pi*H*eps_b*X1) by construction)

CADET-specific bookkeeping: COL_DISPERSION_DEP/FILM_DIFFUSION_DEP evaluate
their power law at the true LOCAL velocity everywhere in the column, not
at a fixed reference velocity. To reproduce Db_i|V=1 and k_i|V=1 exactly
at X=X1 (where v(X1) is the reference velocity), the values supplied to
COL_DISPERSION/FILM_DIFFUSION must be the reference-velocity coefficient
divided by that same reference velocity (or its cube root, for the
1/3-power film-diffusion law):
    COL_DISPERSION[i]  := Db_i|V=1 / v(X1),           so that
        Db_i(X) = COL_DISPERSION[i]*v(X) = Db_i|V=1 * v(X)/v(X1)
    FILM_DIFFUSION[i]  := k_i|V=1 / v(X1)^(1/3),      so that
        k_i(X) = FILM_DIFFUSION[i]*v(X)^(1/3) = k_i|V=1 * (v(X)/v(X1))^(1/3)
This is a bookkeeping requirement of the mapping, not an additional
approximation: with it, every dimensionless group above is reproduced
exactly at the reference velocity, and the correct velocity-scaling
behavior (Eq. 14.15/14.16) holds everywhere else in the column.

===========================================================================
Case-specific notes
===========================================================================
- Pulse timing: injection runs from tau=0 to tau=tau_imp=0.5 (physical
  t=0 to t=tau_imp*L/v_char), and the run continues to tau=tau_max=16 (the
  paper's own printed x-axis range).
- "iave=2" constant-Bi fallback: the paper's own alternative to true
  position-dependent Bi_i(V) (Eq. 14.16), evaluating k_i once at V=0.5:
  k_i|avg = k_i|V=1 * [(1-V0)/(0.5+V0)]^(1/6). Selectable in get_model()
  via film_diffusion_velocity_dep=False, for comparison against the
  default, fully position-dependent treatment.
- col_dispersion_velocity_dep=False in get_model() is an analogous
  ablation of the dispersion relationship (COL_DISPERSION held constant
  at Db_i|V=1 everywhere); the paper itself offers no non-dependent
  variant, so this exists only as a diagnostic option.
